# Interview preparation

## Inputs

- Saved job: title, company, named skills, requirements, location/remote, seniority signals.
- Confirmed profile: relevant roles, projects, skills, gaps.
- Match result: matched skills and missing requirements.
- Optional user notes: interview format, interviewer role, accessibility needs.

Do not invent company facts, interviewer names, funding, culture or recent news. A research checklist
tells the user what to verify; it does not pretend to have verified it.

## Question set

1. Technical questions tied to each named skill. Ask for a real project, a decision, a trade-off and
   what the candidate would change.
2. Competency questions: deadline, disagreement, mistake, leadership, cross-functional work, remote
   collaboration when relevant.
3. Gap questions: an honest path for a missing must-have; adjacent experience and a learning plan.
4. Questions for the recruiter: first 90 days, decision-making, constraints, growth, process/timeline.
5. Research checklist: reread the posting, find one verifiable company update, map requirements to two
   examples, confirm format/time zone/accessibility, check a published salary range if available.

## Practice feedback

Use STAR as a structure check, not a truth check:

- Situation: context and constraint.
- Task: what the candidate owned.
- Action: first-person steps.
- Result: outcome, with a verified metric only if one exists.

Feedback should name what is present and what is missing, then suggest one concrete rewrite. Do not
coach the candidate to fabricate a metric. Do not score personality or "hireability"; score answer
structure and relevance.

## Company research

- Use the employer's own careers page and the original posting.
- Prefer recent, verifiable facts with a date and source.
- Separate "confirmed from the posting" from "to verify".
- Do not infer culture from a few reviews or a slogan.

## Failure handling

- No job: ask for a saved listing; a generic question set is less useful.
- No confirmed experience: focus on education/projects and honest gap framing.
- Answer too short/long: give a length target and a structure, not a script to memorize.
- Sensitive personal topic: do not probe; suggest how to redirect professionally.
